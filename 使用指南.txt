Novabot 使用指南
版本：2026-11-09（schema v16）
适用：Windows，本机 127.0.0.1:19100
维护约定：每次改功能、参数、命令、端口、数据库结构，必须同步更新本文件；测试会检查本文件是否覆盖当前 schema 版本。

============================================================
一、这是什么
============================================================
一个跑在自己电脑上的 QQ 机器人：
- 能接一个或多个 QQ 号（多开），每个号独立连接、参数、人格、记忆
- 会记对话、抽事实、做人物画像、做摘要；有情绪、联想图、指代消解
- 会主动找合适的人私聊（默认关，按作息/关系/回复率）
- 能发语音（GPT-SoVITS），也能做简单的工作助手：笔记、提醒、文档问答
- 网页面板：概览 / 工作台 / 人物 / 记忆 / 接入 / 设置
- 默认只监听本机；开到局域网/公网前必须设面板密码

============================================================
二、启动和停止
============================================================
1. 双击桌面「Novabot」快捷方式（或「启动Novabot.bat」）
   - 第一次启动会自动创建项目自己的 .venv 并安装依赖（需要 Python 3.11+ 和网络）
   - 之后启动直接复用 .venv
   - 从配置读端口（默认 19100）
   - 起服务后等健康检查，再打开 WebView2 桌面窗口
   - 窗口关闭会先确认；确认后后端进程全部退出，不留残余
2. 关闭：直接关桌面窗口，或双击「停止Novabot.bat」
3. 手动启动（排查用）：
   .venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 19100
4. 健康检查：http://127.0.0.1:19100/healthz
5. 页面打不开/白屏：先 Ctrl+F5 强刷；再看 data\logs\server.err.log 尾部

============================================================
三、第一次配置
============================================================
1. 模型（不配就只能收到消息、不会回复）
   复制 config\default.toml 为 config\local.toml，填：
   [llm]
   default = "deepseek"
   [llm.deepseek]
   type = "openai_compat"
   base_url = "https://api.deepseek.com"
   api_key = "sk-..."
   model = "deepseek-chat"
   也可以用假模型先跑界面：
   [llm]
   default = "mock"
   [llm.mock]
   type = "mock"

2. 主人 QQ
   设置 → 安全 → 主人 QQ，填你自己的 QQ。
   笔记/提醒、写操作只对主人私聊开放。
   默认留空；填了才限制主人私聊。

3. 语音（可选）
   config\local.toml 里写：
   [voice]
   enabled = true
   default_engine = "gptsovits"
   [voice.engines.gptsovits]
   type = "gptsovits"
   url = "http://127.0.0.1:9880"
   timeout = 120
   [[voice.refs]]
   id = "short"
   name = "短句"
   engine = "gptsovits"
   audio_path = "C:\\path\\to\\ref.wav"
   prompt_text = "参考音频里说的那句话"
   min_chars = 1
   max_chars = 8
   params = { seed = -1, top_k = 5 }
   设置 → 语音 → 启用语音，选触发模式（对方要求/按概率/每条都发）。
   试听：POST /api/voice/preview {"text":"你好"}

   ｜ 面板「语音」页 ｜
   - 引擎：加 GPT-SoVITS / CosyVoice / OpenAI 兼容 / 自定义 HTTP
     填 id、类型、地址、API Key（可空）、模型/音色、超时、默认参数 JSON
     每条可以「测试」连接；保存后自动重建引擎池
   - 参考音：每条填 id、名称、绑定的引擎、音频路径、参考文本、
     适用字数、权重、情绪标签、合成参数 JSON、选择条件 JSON
     每条都可以「试听」；参数不同，合成效果不同
   - 调试台：输入文本 + 情绪（留空自动），可选自动/指定参考音；
     试听会显示命中的参考音、引擎、时长和原因，只播放不发 QQ
   - 旧 config 里的 [voice.engines.*] 只用于首次播种；之后以面板为准

4. 接入 QQ（OneBot）
   设置 → 接入：填机器人 QQ、OneBot 地址、Token、实现（SnowLuma/NapCat/Lagrange）
   或者顶部「加账号」新建一个。

============================================================
四、多开（多个 QQ 号）
接入页顶部可以直接下载 QQ 底座：选 SnowLuma / NapCatQQ、版本、完整版或 Lite；下载源可选自动测速或手动指定国内镜像。文件落在 data/plugins/downloads，不会自动运行。
============================================================
顶部栏就是账号标签页：
- 「全部」：看所有账号的数据；设置页改的是全局默认值
- 「账号名 + QQ」：只切到这个账号；数据页、工作台、设置都按这个账号走
- 刷新后会记住上次选择；「全部」也会被记住
- 账号右边的圆点：绿=在线，灰=离线，红=停用
- 顶部「账号」按钮：账号管理（切换 / 编辑 / 连接 / 断开 / 删除 / 新增）
- 账号标签可以拖动排序，顺序会保存
- 顶部「加账号」：新建账号
  字段：显示名、机器人 QQ、OneBot 端口（可空自动分配）、实现、连接地址、Token
  新账号只固定「主人身份/人格」，不会复制面板密码、平台令牌、模型密钥；其它参数走全局默认，端口自动错开 6700/5100/6100 段
- 删除账号：账号管理 → 删除；聊天记录保留，以后重建同 id 能接上
- 内部 default 账号不显示、不能新建/删除
- 每个账号独立：OneBot 连接、参数、人格、记忆、笔记/提醒/文档、主动私聊
- 同一个群在两个号下是两份记录，不会串
- 账号没有配置/离线时，标签页会显示离线；不影响其他号

推荐做法：
1. 先加一个号，确认在线、能收能回
2. 再加第二个号，用「全部」看汇总，用账号标签看单号
3. 每个号在「设置」里单独调人格、语音、主动私聊；全局值作为默认
4. 远程部署前设置「面板密码」（见第九节）

============================================================
五、工作台（笔记 / 提醒 / 文档）
============================================================
导航第二项「工作台」。

笔记：
- 新建笔记：标题可空，正文必填；已有笔记点「编辑」可改
- 搜索：本地过滤，不发请求
- 删除：二次确认
- 按当前账号过滤；「全部」时看所有账号

提醒：
- 填内容 + 时间，例如：10分钟后 / 1小时后 / 明天 09:30 / 2026-11-07 20:30
- 快捷按钮：10分钟后 / 1小时后 / 明天 09:00
- 到点由后台直接发 QQ 消息，不经过模型；失败重试 3 次
- 待提醒可以「改时间」或取消

文档知识库：
- 点文档标题可以预览全文
- 在「搜文档内容」里输入关键词，直接看命中的标题/片段/来源行号
- 粘贴 md/txt，或点「选择文件」：支持 md/txt/pdf/docx，pdf/docx 直接导入
- 自动切成约 500 字一片，记行号
- 聊天时会带《标题》和「来源：文件 第 X-Y 行」
- 按当前账号隔离；删除文档后不再召回
- PDF 只抽文本层；扫描版 PDF 需要先 OCR；单文件上限 8 MB
- 复杂 Excel/PPT 不支持

模块状态：
- 默认只列 warn/off/missing；点「显示全部」看 18 个模块
- 点任意模块行可直接进入对应设置/页面（人格、语音、记忆、模型等）
- 绿色 ok、黄色 warn、灰色 off、红色 missing

============================================================
六、让机器人用工具（默认关）
============================================================
工具默认关闭，避免多花 token。
设置 → 工具 → 启用工具。
可用：
- current_time：现在几点
- add_note / search_notes：记笔记/查笔记（仅主人私聊）
- add_reminder / list_reminders：加提醒/查提醒（仅主人私聊）

可以直接说：
- 「记一下：周五交周报」
- 「我有哪些提醒」
- 「十分钟后提醒我喝水」

限制：
- 群聊只能用 current_time；写操作会被拒绝
- 一次回复最多 2 轮工具、每轮最多 5 个，结果截断
- 每次调用写 tool_calls 审计，接口 GET /api/tools/calls

============================================================
七、文件传输
设置 → 文件；模块 → 文件传输。
默认只和主人收发、发文件需要审批；文件只能放 data/files 的 inbox/outbox，不能填电脑其他路径。
敏感文件名和密钥内容会在上传/发送前拒绝。模型只能请求发送，主人在面板批准后才真正上传。

八、隐私隔离
设置 → 隐私：
- 启用隐私隔离（默认开）
- 允许同一个人跨私聊回忆（默认关，只限同一个人自己的私聊）
- 群聊里带人物画像（默认关）
- 带知识文档（默认关）
- 拦截联系方式（手机号/邮箱）
- 检测到泄露：改成拒绝回答 / 只记录
- 额外保密词（列表）

默认行为：
- 群聊只读当前群，不读任何私聊
- 别人的私聊只读当前这个私聊
- 主人私聊只读主人私聊，其他人私聊不进来
- 回复里出现其他会话原文/手机号/保密词，会替换成「这个不方便在这里说。」
记忆页顶部也有「隐私设置」入口。

九、模块（额外功能）
多账号隔离：每个 QQ 号自己的设置、记忆、TTS 参考音、表情库、文件、权限和 DSH 工作区独立；切换顶部账号后各页自动切数据。
设置 → 接入：可填 SnowLuma 命令/工作目录/端口，Novabot 启动时端口没开就自动拉起。
聊天 → 会话：每个私聊/群聊独立 DSH 会话，可设自动压缩/切换轮数。
设置 → 模型 → 自动检测模型；启动时也会自动探测 DSH。
人格卡在「人格」页新建/编辑；每个账号可以启用不同人格。
隐私只保护聊天原文；人物资料、昵称、别名和群聊谁是谁可以查。
DSH Agent 支持联网搜索；聊天权限里可开关「联网搜索」，默认只有主人开。
聊天权限跟账号走：主人在群里也保持主人档，也可按 QQ 设账号级档位。
模块设置弹窗可一键同步通用行为到其他 bot；TTS/端口/接口/凭据不会同步。
设置页只保留模型/工具/安全/界面/调试；其他参数在对应页面右上角打开。
左侧「生活」页：模拟作息和当前活动，默认每天最多 6 次；四个时段次数可单独调高，先预览再开启。
聊天 → 媒体：图片用本机视觉模型，语音用本地 faster-whisper，视频抽帧后识别。
聊天 → 媒体：可开关读图/视频/语音条，并填视觉、Whisper、ffmpeg 配置。
记忆页默认锁定；打开「编辑保险」后，对话/事实/摘要的文字可点击改，右侧垃圾桶可删。
侧边栏「聊天」：语音页可设语音+文字、只发语音、部分转语音和转换概率。隐私、聊天权限、白名单、真实性、回复可以页内直接改；权限覆盖只列当前账号白名单里的私聊/群。表情包每个 QQ 号独立库表情包每个 QQ 号独立库；会先理解画面/文字/情绪/含义，没合适的就不发，不随机瞎配；默认只主人私聊可用；「偷表情包」默认关，自动配表情私聊 12%、群聊 6%。自然语言可以说「发个开心的表情包」。

模块 → B站翻唱：搜 B 站视频，直接提取音频（m4a），配好引擎/音色后可以 RVC 翻唱。自然语言「提取B站音频《歌名》」也可以。
模块 → 权限分级：主人私聊单独档；档位 1/2/3 可自定义文件读写、命令、翻唱、换头像、改名称、白名单、群管；每个聊天可覆盖。自然语言命令会先按权限执行，没权限直接说做不到。
设置 → 真实：真实性优先、工作模式、拦截假称完成。工作模式只讲可验证结果；没工具证据不说“已经删好/改好”；普通聊天可保留玩笑和人设，但事实、能力、记忆不许编。

模块 → 权限分级：主人私聊单独档；档位 1/2/3 可自定义读文件/改文件/删文件/运行命令/发文件；每个私聊/群聊可以单独覆盖，不设就按默认档。权限会同时限制 Novabot 工具和 DSH 工作区工具。
顶栏「模块」是扩展入口：
- B站翻唱：网易云搜歌、音色库、外部换声引擎、任务/历史
- 平台接入：DSH / TRAE / CodeBuddy
- 语音工坊：TTS、参考音
- 生图/自动任务：接口位已预留

B站翻唱：
1. 设置 → 模块，打开「启用翻唱模块」
2. 填「翻唱引擎地址」（外部 RVC/so-vits-svc HTTP 服务），或先只搜歌/导入音色
3. 模块 → B站翻唱，搜歌、选音色、变调，提交
4. 任务完成后试听/下载 wav

十、聊天设置
设置 → 聊天：
- 私聊接入：所有人 / 仅白名单 / 只回主人 / 关闭私聊
- 群聊接入：所有群 / 仅白名单群 / 关闭群聊
- 私聊白名单、群白名单：默认折叠显示前几项，点「展开」后是可上下滚动的列表；底部输入 QQ/群号，回车添加，点 × 删除
- 主人称呼：主人说话时模型怎么称呼对方，比如「老板」
- 主人别名：可选，只影响称呼提示

白名单模式下：
- 私聊主人始终允许
- 群白名单为空 = 不允许任何群
- 被拦下的消息不记账、不回、不耗 token

十一、记忆和人格
============================================================
- 对话原文：episodes；事实：facts；摘要：gists；人物：people
- 情绪：amygdala；联想图：graph；人物画像：profile
- 指代消解：群聊「他/她」会尝试补一行指代提示
- 召回：按意图取画像/最近/事实/文档，有字数预算
- 人格：设置 → 人格；人格卡按账号切换
- 记忆页分「概览 / 对话 / 事实 / 摘要 / 人物 / 知识」六个分区，顶部有全局搜索；对话、事实、摘要、人物、知识都能搜
- 记忆页顶部统计卡可点进对应分区；右上角「记忆参数」直接去设置 → 记忆

预算（防止越聊越贵）：
- 历史 1000 字（llm.history_chars）
- 记忆召回 300 字（memory.recall_chars）
- 画像 240 字（memory.profile_chars）
- 文档最多 2 片
- 超了从最旧/最少用的开始丢

============================================================
十二、主动私聊（默认关）
============================================================
设置 → 主动：
1. 先开「只算不发」，跑一天看日志里的候选和理由
2. 再关「只算不发」
3. 建议：每人每天 1 条、安静时段 23-8 点
规则：
- 按真实消息学作息（工作日/周末分开）
- 看沉默时长、关系、有没有话题、回复率
- 被无视退避 1→3→7 天；回复清零
- 只发私聊，发一条等回复，不连续追问
接口：
- GET /api/proactive/status
- POST /api/proactive/preview
- POST /api/proactive/fire
- GET /api/proactive/logs

============================================================
十三、人格卡
============================================================
导航「人格」页：
- 当前人格 hero + 其他人格卡；每张卡按账号隔离
- 编辑器六区：基本资料 / 身份背景 / 性格 / 说话方式 / 边界 / 示例
- 别名、标签、口头禅、禁用词用标签输入；性格和示例是结构化行
- 顶部实时预览；编辑已有卡时 id 只读
- 保存后可「启用」，写入 persona.current
- 人格卡默认是空白，id、别名、标签、说话方式都由使用者自己定
- 每张卡按账号隔离，切换顶部账号即可使用不同人格
- 关键词：点卡片「关键词」加规则
  关键词（逗号分隔）、匹配方式（任一/全部/正则）
  效果一行一个 `target|delta|duration`，如 `trait.傲娇|-0.4|300`
  概率/冷却/优先级/备注；可编辑/删除
- 手写区：点卡片「手写区」加片段
  标题、类型（说话方式/禁忌/背景/示例/其他）、内容、排序、权重、启停
  会按 `persona.raw_budget_chars` 预算进 prompt
人格卡管静态骨架；关键词管临时变化；手写区管细节。

============================================================
十四、DSH / TRAE / CodeBuddy
DSH 插件会为每个 bot 建工作区，并为每个 QQ 会话建 DSH 会话；会话标题是 Novabot·角色·私聊/群聊。host 插件更新后需要重启 DSH 一次才会加载。
DSH 连上后，概览的模型会显示 DSH Agent；平台页有「测试模型」按钮，不写记忆、不发 QQ，直接验证模型是否能回。群里默认只回 @ / 唤醒词（可开「戳一戳也算唤醒」），私聊必回。
============================================================
目标：不只接 LLM API，也能让 DSH 的模型/会话参与回复，并让 TRAE / CodeBuddy
通过 MCP 直接读写 Novabot 的记忆和人格。

A. DSH 模型桥接（自动检测）
1. 把 `dsh-plugin/novabot` 整个目录作为插件包安装（或拷到 DSH 的 plugins），重启 DSH
   包内已声明 dsh.bundle.patch，正常不会再报 `declares no dsh.bundle`
2. 日志出现：Novabot 插件已加载：/novabot/api/chat
3. 设置 → 平台：
   - 自动检测：开（默认）
   - 检测到就自动连接：开（默认）
   - DSH 地址：http://127.0.0.1:<DSH端口>（默认 55784）
4. 平台页会显示 DSH「在线/已自动连接」；检测到插件健康会自动写：
   Agent 类型 DSH + /novabot/api/chat + 开启外部 Agent
5. 插件关闭/DSH 重启时，平台页会显示离线，并自动退回普通模型，避免回复全失败
6. 之后 QQ 回复走 DSH 当前模型；会话 id 映射到 Novabot 的 chat_id
   （平台页能看到「外部会话 → chat_id」列表）

B. DSH 工作区
- 每个 bot（顶部标签）一个 DSH 工作区，名字是 `Novabot·<标签名字>`
- 目录默认 `~/Novabot/workspaces/<账号 id>`
- 双击顶部账号标签可以改名字；改名后下一条对话会把 DSH 工作区改名
- 账号管理里的「编辑」也能改名字

============================================================
十五、安全（远程必看）
============================================================
默认：不设密码，只监听 127.0.0.1，本机使用。
要开到局域网/公网：
1. 设置 → 安全 → 面板密码（设置后所有 /api/* 要带 X-Panel-Token）
2. 设置 → 安全 → 平台令牌（给 /api/platform/* 用，和面板密码分开）
3. 网页首次 401 会弹登录框；密码只存本机浏览器
4. 不要把端口直接暴露到公网；至少加 HTTPS/反代和防火墙
5. 机器人 token/密码不要写进截图或公开仓库

============================================================
十六、设置页说明
媒体：设置 → 媒体。图片/表情走视觉模型，语音走 Whisper 兼容接口，视频要本机 ffmpeg。视觉默认复用聊天模型；DSH Agent/纯文本模型请选「单独视觉接口」。没有配置时会明确提示未识别，不会假装看到。
输出：长回复拆条默认开，超过 42 字开始按句子/分句拆，最多 4 条只是上限，不是固定回几句；拆条之间会随机等 0.25~0.7 秒。短句、嗯/好这类会合并，URL 和代码不拆。
============================================================
- 外观：6 套主题（纸白/晨雾/藕荷/石墨/深蓝/墨绿），只影响浏览器

十九、常见问题
============================================================
Q: 页面白屏/样式不对
A: Ctrl+F5；确认 /static/app.css、app.core.js、app.pages.js、app.main.js 能访问；看浏览器 Console

Q: 双击启动提示 .venv\Scripts\pythonw.exe not found
A: 新版「启动Novabot.bat」会自动创建 .venv 并装依赖；失败时先装 Python 3.11+，再手动运行 python -m venv .venv 和 .venv\Scripts\python.exe -m pip install -e .

Q: 启动说端口被占
A: 停止Novabot.bat；或改 config 里的端口；检查是否还有旧 pythonw 进程

Q: 能收消息但不回复
A: 设置 → 模型 是否配置；llm.default 是否指向存在的模型；看日志

Q: 语音没发出来
A: GPT-SoVITS 是否启动、/docs 是否可访问；参考音路径是否存在；语音预算是否太短；失败会自动发文字

Q: 多开只有「全部」，没有账号标签
A: 还没加账号。点顶部「加账号」，填机器人 QQ 和 OneBot 地址

Q: 切了账号但设置没变
A: 设置页顶部会显示「账号：xxx」；确认不是「全部账号（全局）」；单项覆盖保存在该账号下

Q: 远程访问 401
A: 输入面板密码；平台接口用 X-Platform-Token；密码/令牌在设置 → 安全

Q: 测试留下临时目录
A: python -m scripts.cleanup_test_procs
